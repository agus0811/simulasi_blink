Simulasi Arduino LED Blink

Klik tombol di bawah untuk menguji kedipan lampu pada Pin 13

STATUS: MATI (LOW)
Pilih Kecepatan Kedip:
Lihat Kode Arduino (sketch.ino) 
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}
